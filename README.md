# Agentic AI Secure SDLC Assistant

A Final Year Computer Engineering Project that integrates AI agents with Secure Software Development Lifecycle (Secure SDLC) practices to assist developers in identifying, analysing, and mitigating security vulnerabilities throughout software development.

## Tech Stack

- React
- Django REST Framework
- PostgreSQL
- LangGraph
- Semgrep
- Bandit
- CodeQL
- Trivy
- Docker

## Features

- AI Requirement Analysis
- Threat Modelling
- Secure Code Review
- Vulnerability Detection
- Dependency Scanning
- Security Test Generation
- Deployment Verification
